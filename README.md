# CBSE Physics RAG Tutor

An AI-powered multimodal Physics tutor that generates CBSE-style long-form answers using Retrieval-Augmented Generation (RAG) grounded strictly in physics textbooks.

The system uses semantic retrieval over HC Verma and IE Irodov books, intelligent workflow routing, persistent conversation memory, and multimodal diagram understanding to provide structured, citation-backed physics explanations.

---

# Features

## Textbook-Grounded RAG

Answers are generated strictly from:

- HC Verma Volume 1
- HC Verma Volume 2
- IE Irodov

The system avoids hallucinations and returns:

```text
No relevant information found in the knowledge base.
```
